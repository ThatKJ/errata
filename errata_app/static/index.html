Errata needs answers that were already sent. This loads a synthetic fact sheet for a fictional company (20 facts) into Hindsight, then drafts 30 customer answers with Hindsight reflect and records which facts each answer cited.

Each draft is a real local model call, so this takes tens of minutes on a laptop. The workspace is kept, so you only do this once.
